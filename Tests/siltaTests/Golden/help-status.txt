### silta status

OVERVIEW: Print a one-line status: workspace, app, inbox count and your claimed
tasks.

Bare silta runs this. It is a read: no fetch, no index write. inbox counts what
silta inbox shows for you; claimed lists your exact session's claims.

USAGE: silta status [--ws <ws>] [--approved <approved>] [--json] [--quiet] [--verbose]

GLOBAL OPTIONS:
  --ws <ws>               Use this workspace; default is inferred or saved.
  --approved <approved>   The human's words approving this command in chat;
                          default is none.
  --json                  Print the JSON envelope on stdout; default is text.
  --quiet                 Hide success text; warnings and errors still show.
  --verbose               Mirror command diagnostics to stderr.

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.
