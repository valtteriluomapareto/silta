### silta backup

OVERVIEW: Create a whole-database SQLite snapshot.

Includes every workspace, regardless of --ws. Keeps seven on-demand snapshots
separately from daily and pre-restore backups. Does not export or commit a text
tree.

USAGE: silta backup [--ws <ws>] [--approved <approved>] [--json] [--quiet] [--verbose]

GLOBAL OPTIONS:
  --ws <ws>               Use a workspace; default is inferred or saved.
  --approved <approved>   The human's chat approval; default is none.
  --json                  Print JSON; default is text.
  --quiet                 Hide success text; default is off.
  --verbose               Mirror diagnostics; default is off.

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.
