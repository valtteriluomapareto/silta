### silta repo

OVERVIEW: Operate on registered repositories.

USAGE: silta repo [--ws <ws>] [--approved <approved>] [--json] [--quiet] [--verbose] <subcommand>

GLOBAL OPTIONS:
  --ws <ws>               Use this workspace; default is inferred or saved.
  --approved <approved>   The human's words approving this command in chat;
                          default is none.
  --json                  Print the JSON envelope on stdout; default is text.
  --quiet                 Hide success text; warnings and errors still show.
  --verbose               Mirror command diagnostics to stderr.

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  fetch                   Fetch a repo, or all registered repos in the
                          workspace, without prompting.

  See 'silta help repo <subcommand>' for detailed help.

### silta repo fetch

OVERVIEW: Fetch a repo, or all registered repos in the workspace, without
prompting.

USAGE: silta repo fetch [--ws <ws>] [--approved <approved>] [--json] [--quiet] [--verbose] [<repo>]

ARGUMENTS:
  <repo>                  The repository slug; omitted means all registered
                          repos.

GLOBAL OPTIONS:
  --ws <ws>               Use this workspace; default is inferred or saved.
  --approved <approved>   The human's words approving this command in chat;
                          default is none.
  --json                  Print the JSON envelope on stdout; default is text.
  --quiet                 Hide success text; warnings and errors still show.
  --verbose               Mirror command diagnostics to stderr.

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.
