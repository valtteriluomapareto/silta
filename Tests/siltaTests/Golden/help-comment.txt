### silta comment

OVERVIEW: Post task discussion; a claimer's handoff releases its claim.

The default subcommand is `comment post`; see `silta comment post --help`.
Ask: silta comment AC-1 --kind question -m "Which API?"
Answer: silta comment AC-1 --kind answer --reply-to AC-1/1 -m "Use v2."
Accept (asker or current claimer): silta comment accept AC-1/2
Post findings as roots; replies normalize to their root.
A claimer's handoff releases its claim; see `silta guide questions`.

USAGE: silta comment [--ws <ws>] [--approved <approved>] [--json] [--quiet] [--verbose] <subcommand>

GLOBAL OPTIONS:
  --ws <ws>               Use this workspace; default is inferred or saved.
  --approved <approved>   The human's words approving this command in chat;
                          default is none.
  --json                  Print the JSON envelope on stdout; default is text.
  --quiet                 Hide success text; warnings and errors still show.
  --verbose               Mirror command diagnostics to stderr.

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  resolve                 Resolve discussion threads atomically.
  reopen                  Reopen discussion threads atomically.
  delete                  Soft-delete your own post, retaining its ref and
                          thread.
  accept                  Accept an answer as the asker or current claimer and
                          resolve the thread.

  See 'silta help comment <subcommand>' for detailed help.

### silta comment post

OVERVIEW: Post task discussion; a claimer's handoff releases its claim.

USAGE: silta comment post [<options>] <target>

ARGUMENTS:
  <target>                The task reference.

GLOBAL OPTIONS:
  --ws <ws>               Use this workspace; default is inferred or saved.
  --approved <approved>   The human's words approving this command in chat;
                          default is none.
  --json                  Print the JSON envelope on stdout; default is text.
  --quiet                 Hide success text; warnings and errors still show.
  --verbose               Mirror command diagnostics to stderr.

OPTIONS:
  -m, --message <message> Supply the markdown body; default is none.
  -F <F>                  Read UTF-8 from a file, or - for stdin; default is
                          none.
  --allow-secret          Retain detected secrets (human-only; use file input
                          for a body retry).
  --kind <kind>           One of comment, question, answer, decision, handoff;
                          default is comment. A handoff names state, next step,
                          open questions and branch/sha.
  --reply-to <reply-to>   Join this post's thread; replies normalize to its
                          root; default is none.
  --to <to>               Recipient: complete actor or me; repeatable, default
                          none. Questions default to the human; @me means
                          human:<USER>.
  --from <from>           Cite a note: reference; default is none.
  --version               Show the version.
  -h, --help              Show help information.
