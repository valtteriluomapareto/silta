### silta ws

OVERVIEW: List, select and edit workspaces.

USAGE: silta ws [--ws <ws>] [--approved <approved>] [--json] [--quiet] [--verbose] <subcommand>

GLOBAL OPTIONS:
  --ws <ws>               Use this workspace; default is inferred or saved.
  --approved <approved>   The human's words approving this command in chat;
                          default is none.
  --json                  Print the JSON envelope on stdout; default is text.
  --quiet                 Hide success text; warnings and errors still show.
  --verbose               Mirror command diagnostics to stderr.

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  ls                      List workspace slugs, names and task prefixes.
  use                     Set the default workspace outside registered
                          repositories.
  edit                    Edit workspace YAML (human-only).
  show                    Print the selected workspace YAML without editing it.
  rm                      Remove one workspace from a human terminal.

  See 'silta help ws <subcommand>' for detailed help.

### silta ws edit

OVERVIEW: Edit workspace YAML (human-only).

Keep the baseline comment from ws show or a retained editor draft. If stale,
review a fresh ws show before reapplying your edits. An unstamped file uses the
configuration at command start. Releasing retired slugs from a file requires
the baseline comment.
Preview map changes and blockers without approval using --dry-run -F <file>.
Update Acme YAML (human): silta ws edit acme -F acme.yml

USAGE: silta ws edit [--ws <ws>] [--approved <approved>] [--json] [--quiet] [--verbose] [<workspace>] [-F <F>] [--dry-run]

ARGUMENTS:
  <workspace>             The workspace slug; defaults to repository location,
                          then the saved default.

GLOBAL OPTIONS:
  --ws <ws>               Use this workspace; default is inferred or saved.
  --approved <approved>   The human's words approving this command in chat;
                          default is none.
  --json                  Print the JSON envelope on stdout; default is text.
  --quiet                 Hide success text; warnings and errors still show.
  --verbose               Mirror command diagnostics to stderr.

OPTIONS:
  -F <F>                  Read UTF-8 YAML from a file, or - for stdin; default
                          is none.
  --dry-run               Preview map changes and blockers without saving.
                          Requires -F.
  --version               Show the version.
  -h, --help              Show help information.

### silta ws rm

OVERVIEW: Remove one workspace from a human terminal.

Preview the removal without saving with --dry-run. The saved default and active
or uninspectable clone registrations require --allow-active. Removal saves a
SQLite backup and a workspace recovery tree.

USAGE: silta ws rm [--ws <ws>] [--approved <approved>] [--json] [--quiet] [--verbose] <workspace> [--dry-run] [--allow-active]

ARGUMENTS:
  <workspace>             The exact workspace slug to remove.

GLOBAL OPTIONS:
  --ws <ws>               Use this workspace; default is inferred or saved.
  --approved <approved>   The human's words approving this command in chat;
                          default is none.
  --json                  Print the JSON envelope on stdout; default is text.
  --quiet                 Hide success text; warnings and errors still show.
  --verbose               Mirror command diagnostics to stderr.

OPTIONS:
  --dry-run               Preview owned rows and active selection without
                          saving.
  --allow-active          Allow removing the saved default or unregistering
                          live or uninspectable clones.
  --version               Show the version.
  -h, --help              Show help information.
