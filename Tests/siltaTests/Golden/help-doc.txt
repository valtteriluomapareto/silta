### silta doc

OVERVIEW: Read and edit stored documents.

USAGE: silta doc [--ws <ws>] [--approved <approved>] [--json] [--quiet] [--verbose] <subcommand>

GLOBAL OPTIONS:
  --ws <ws>               Use this workspace; default is inferred or saved.
  --approved <approved>   The human's words approving this command in chat;
                          default is none.
  --json                  Print the JSON envelope on stdout; default is text.
  --quiet                 Hide success text; warnings and errors still show.
  --verbose               Mirror command diagnostics to stderr.

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  show                    Read stored revisions, diffs or paged comments.
  ls                      List current documents and pending revisions.
  edit                    Accept a complete document revision (human-only).
  archive                 Archive a document and remove its live attachments
                          (human-only).

  See 'silta help doc <subcommand>' for detailed help.

### silta doc archive

OVERVIEW: Archive a document and remove its live attachments (human-only).

Keeps revision history, comments and verification evidence.
An already archived doc without live attachments changes nothing.
Archive (human): silta doc archive rules

USAGE: silta doc archive [--ws <ws>] [--approved <approved>] [--json] [--quiet] [--verbose] <slug>

ARGUMENTS:
  <slug>                  Doc slug or doc:slug, without a revision.

GLOBAL OPTIONS:
  --ws <ws>               Use this workspace; default is inferred or saved.
  --approved <approved>   The human's words approving this command in chat;
                          default is none.
  --json                  Print the JSON envelope on stdout; default is text.
  --quiet                 Hide success text; warnings and errors still show.
  --verbose               Mirror command diagnostics to stderr.

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

### silta doc edit

OVERVIEW: Accept a complete document revision (human-only).

Use -F for complete UTF-8 Markdown, or --keep-body to retain it.
New docs need --title and --about. About refs replace the whole set.
Input: at most 65536 bytes. Kind stays fixed unless --kind is explicit.
Read editing rules with silta guide recipes.
Create (human): silta doc edit api -F api.md --title API --about app:api
Preserve (human): silta doc edit api --keep-body --about app:api

USAGE: silta doc edit [--ws <ws>] [--approved <approved>] [--json] [--quiet] [--verbose] <slug> [-F <file>] [--keep-body] [--title <title>] [--kind <kind>] [--about <about> ...] [--allow-secret]

ARGUMENTS:
  <slug>                  Doc slug or doc:slug, without a revision.

GLOBAL OPTIONS:
  --ws <ws>               Use this workspace; default is inferred or saved.
  --approved <approved>   The human's words approving this command in chat;
                          default is none.
  --json                  Print the JSON envelope on stdout; default is text.
  --quiet                 Hide success text; warnings and errors still show.
  --verbose               Mirror command diagnostics to stderr.

OPTIONS:
  -F <file>               Read complete UTF-8 Markdown from a file, or - for
                          stdin; exclusive with --keep-body.
  --keep-body             Copy the accepted owned body; exclusive with -F.
  --title <title>         One line of at most 120 characters; required for a
                          new doc, otherwise preserved.
  --kind <kind>           contract, flow, runbook or reference; inferred for a
                          new doc, otherwise preserved.
  --about <about>         Canonical map ref; repeat to replace the complete
                          set; required for a new doc.
  --allow-secret          Retain detected secrets (human-only).
  --version               Show the version.
  -h, --help              Show help information.

### silta doc ls

OVERVIEW: List current documents and pending revisions.

USAGE: silta doc ls [--ws <ws>] [--approved <approved>] [--json] [--quiet] [--verbose] [--about <about>] [--archived] [--offset <offset>] [--limit <limit>]

GLOBAL OPTIONS:
  --ws <ws>               Use this workspace; default is inferred or saved.
  --approved <approved>   The human's words approving this command in chat;
                          default is none.
  --json                  Print the JSON envelope on stdout; default is text.
  --quiet                 Hide success text; warnings and errors still show.
  --verbose               Mirror command diagnostics to stderr.

OPTIONS:
  --about <about>         Filter by a canonical app, edge, service or topic ref.
  --archived              Include archived documents.
  --offset <offset>       Number of entries to skip. (default: 0)
  --limit <limit>         Number of entries, from 1 to 100. (default: 20)
  --version               Show the version.
  -h, --help              Show help information.

### silta doc show

OVERVIEW: Read stored revisions, diffs or paged comments.

USAGE: silta doc show [--ws <ws>] [--approved <approved>] [--json] [--quiet] [--verbose] <ref> [--rev <rev>] [--lines <lines>] [--diff] [--comments] [--offset <offset>] [--limit <limit>]

ARGUMENTS:
  <ref>                   Doc slug, doc:slug or doc:slug@revision[/comment].

GLOBAL OPTIONS:
  --ws <ws>               Use this workspace; default is inferred or saved.
  --approved <approved>   The human's words approving this command in chat;
                          default is none.
  --json                  Print the JSON envelope on stdout; default is text.
  --quiet                 Hide success text; warnings and errors still show.
  --verbose               Mirror command diagnostics to stderr.

OPTIONS:
  --rev <rev>             Positive revision; must agree with a revision in the
                          ref.
  --lines <lines>         Positive rendered line N or inclusive range A-B;
                          default is at most 400 lines.
  --diff                  Compare against the recorded base revision.
  --comments              Read revision comments.
  --offset <offset>       Comment entries to skip; requires --comments; default
                          is 0.
  --limit <limit>         Comment entries, from 1 to 20; requires --comments;
                          default is 20.
  --version               Show the version.
  -h, --help              Show help information.
