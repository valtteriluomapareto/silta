### silta task

OVERVIEW: Keep task work, plans and results in the local backlog.

USAGE: silta task [--ws <ws>] [--approved <approved>] [--json] [--quiet] [--verbose] <subcommand>

GLOBAL OPTIONS:
  --ws <ws>               Use this workspace; default is inferred or saved.
  --approved <approved>   The human's words approving this command in chat;
                          default is none.
  --json                  Print the JSON envelope on stdout; default is text.
  --quiet                 Hide success text; warnings and errors still show.
  --verbose               Mirror command diagnostics to stderr.

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  add                     Add a proposal; --start claims work requested by the
                          human.
  ls                      List workspace tasks, including your own proposals.
  show                    Read task bodies, claim, handoff and unresolved
                          discussion.
  start                   Claim a todo task for this exact actor and session.
  submit                  Submit doing work for review and release its claim.
  done                    Complete a task with its result and optional app
                          commit.
  drop                    Drop an open task and record why.
  plan                    Store a plan revision or tick a top-level checkbox.
  from-plan               Import Markdown steps; preview or safely remove the
                          source.
  edit                    Edit task fields; approval is needed unless you hold
                          its claim.
  triage                  Accept or drop proposals in one approved batch
                          (human-only).
  archive                 Hide a task from the default backlog.
  keep                    Keep a task visible regardless of its closed age.
  link                    Link a task to a reference in this workspace or an
                          external URL.
  promote                 Record an external tracker and make the task
                          read-only (human-only).
  block                   Record blockers; Silta sends nothing.
  unblock                 Return a blocked batch to todo; an open blocker needs
                          the human's go-ahead.

  See 'silta help task <subcommand>' for detailed help.

### silta task add

OVERVIEW: Add a proposal; --start claims work requested by the human.

USAGE: silta task add [<options>] <title>

ARGUMENTS:
  <title>                 The task title.

GLOBAL OPTIONS:
  --ws <ws>               Use this workspace; default is inferred or saved.
  --approved <approved>   The human's words approving this command in chat;
                          default is none.
  --json                  Print the JSON envelope on stdout; default is text.
  --quiet                 Hide success text; warnings and errors still show.
  --verbose               Mirror command diagnostics to stderr.

OPTIONS:
  -m, --message <message> Supply the markdown body; default is none.
  -F <F>                  Read UTF-8 from a file, or - for stdin; default is
                          none.
  --allow-secret          Retain detected secrets (human-only; use file input
                          for a body retry).
  --priority <priority>   Backlog priority: 1, 2 or 3. (default: 2)
  --start                 Start and claim this requested work.
  --parent <parent>       The parent task reference; default is none.
  --app <app>             The app slug, or none for non-code work; omitted
                          takes the parent's app.
  --topic <topic>         An existing topic slug; default is none. Repeatable.
  --from <from>           The source note: reference; default is none.
  --version               Show the version.
  -h, --help              Show help information.

### silta task edit

OVERVIEW: Edit task fields; approval is needed unless you hold its claim.

`--print` outputs the document; edit it and return it with `-F`.
Order: ## Title, ## Description, ## Acceptance, ## Plan, ## Result.
Each heading is followed by a tilde fence (~~~ or longer) around the value.
Choose a fence longer than any tilde run in the values.
Empty fields hold one blank line; changed plans make revisions.
Agents can't clear a stored Plan or Result.

USAGE: silta task edit [--ws <ws>] [--approved <approved>] [--json] [--quiet] [--verbose] <ref> [-F <F>] [--print] [--allow-secret]

ARGUMENTS:
  <ref>                   The task reference.

GLOBAL OPTIONS:
  --ws <ws>               Use this workspace; default is inferred or saved.
  --approved <approved>   The human's words approving this command in chat;
                          default is none.
  --json                  Print the JSON envelope on stdout; default is text.
  --quiet                 Hide success text; warnings and errors still show.
  --verbose               Mirror command diagnostics to stderr.

OPTIONS:
  -F <F>                  Read UTF-8 Markdown from a file, or - for stdin;
                          default is none.
  --print                 Print the current document without editing; needs no
                          approval.
  --allow-secret          Retain secrets with human approval.
  --version               Show the version.
  -h, --help              Show help information.

GLOBAL OPTIONS:
  --ws <ws>               Use this workspace; default is inferred or saved.
  --approved <approved>   The human's words approving this command in chat;
                          default is none.
  --json                  Print the JSON envelope on stdout; default is text.
  --quiet                 Hide success text; warnings and errors still show.
  --verbose               Mirror command diagnostics to stderr.

OPTIONS:
  --parent <parent>       The parent task reference; default is none. Created
                          tasks inherit its app.
  --split                 Create at most ten subtasks instead of a checklist.
  --dry-run               Preview content and statuses without creating tasks.
  --delete                Remove an unchanged untracked source after commit;
                          never a harness file.
  --allow-secret          Retain detected secrets with human approval.
  --version               Show the version.
  -h, --help              Show help information.
