### silta export

OVERVIEW: Write one workspace as a deterministic text tree for backup and diff.

The tree goes to <root>/<workspace>. It replaces only an absent, empty or
previously exported directory, never one inside a registered repo. Repo paths
and worktrees are not written; configured values are written as stored. It
stages in a hidden .<workspace>.export-XXXXXX next to the tree; one it can't
remove, or a crash left, is an export_leftover warning for the human.
Unreadable entries refuse the target.

USAGE: silta export [--ws <ws>] [--approved <approved>] [--json] [--quiet] [--verbose] [--to <root>] [--commit]

GLOBAL OPTIONS:
  --ws <ws>               Use a workspace; default is inferred or saved.
  --approved <approved>   The human's chat approval; default is none.
  --json                  Print JSON; default is text.
  --quiet                 Hide success text; default is off.
  --verbose               Mirror diagnostics; default is off.

OPTIONS:
  --to <root>             The export root; the tree goes to <root>/<workspace>.
                          Defaults to $SILTA_HOME/exports.
  --commit                Commit only the workspace subtree; default is off.
                          Ignored files produce warnings; an unchanged tree
                          makes no commit.
  --version               Show the version.
  -h, --help              Show help information.
