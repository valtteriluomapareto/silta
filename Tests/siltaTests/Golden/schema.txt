silta schema  Describe the commands, their flags, their --json data and the error codes.
silta ws ls  List workspaces; ask in chat before editing configuration.
silta ws use  Select the current workspace.
silta ws edit  Edit workspace YAML (human-only).
silta ws show  Print the current workspace YAML without editing it.
silta init  Initialize or scan repos; select with ws use; configuration editing is human-only.
silta repo fetch  Fetch a repo, or all registered repos in the workspace, without prompting.
silta task add  Add a proposal; --start claims work requested by the human.
silta task ls  List workspace tasks, including your own proposals.
silta task show  Read task bodies, claim, handoff and unresolved discussion.
silta task start  Claim a todo task for this exact actor and session.
silta task submit  Submit doing work for review and release its claim.
silta task done  Complete a task with its result and optional app commit.
silta task drop  Drop an open task and record why.
silta task plan  Store a plan revision or tick a top-level checkbox.
silta task from-plan  Import Markdown steps; preview or safely remove the source.
silta task edit  Edit task fields; approval is needed unless you hold its claim.
silta task triage  Accept or drop proposals in one approved batch.
silta task archive  Hide a task from the default backlog.
silta task keep  Keep a task visible regardless of its closed age.
silta task link  Link a task to a reference in this workspace or an external URL.
silta task promote  Record an external tracker and make the task read-only (human-only).
silta task block  Record blockers; Silta sends nothing.
silta task unblock  Return a blocked batch to todo; an open blocker needs the human's go-ahead.
silta code show  Read a committed file, optionally selecting lines.
silta code grep  Search committed text, returning app-relative paths and line numbers.
silta code log  List commit SHA and subject at the selected ref.
silta code ls  List immediate committed names in an app-relative directory.
silta where  Resolve the workspace, repository and app for a local path.
silta doctor  Diagnose database, git and data across all workspaces without repairs.
silta comment  Post task discussion; a claimer's handoff releases its claim.
silta comment resolve  Resolve discussion threads atomically.
silta comment reopen  Reopen discussion threads atomically.
silta comment delete  Soft-delete your own post, retaining its ref and thread.
silta comment accept  Accept an answer as the asker or current claimer and resolve the thread.
silta brief  Read budgeted local context for the current task.
silta guide  Read the agent manual, or one topic.
silta agents install  Preview owned harness edits; confirm with --apply <token>.
silta agents uninstall  Preview removal of selected, unedited Silta ownership.
details: silta schema <command>

global flags:
  --ws <ws>  optional: Use this workspace instead of the current selection.
  --approved <approved>  optional: The human's words approving this command in chat.
  --json  optional: Print the JSON envelope on stdout instead of text.
  --quiet  optional: Hide success text; warnings and errors still show.
  --deterministic  optional: Allow deterministic overrides outside temporary homes; never at the real home.
  --verbose  optional: Mirror command diagnostics to stderr.

error codes:
  usage  exit 1, next by agent: Read `silta <cmd> --help` and fix the call
  invalid  exit 1, next by agent: Read `silta <cmd> --help` and fix the call
  not_found  exit 2, next by agent: Check the ref, or carry on without silta
  unregistered  exit 2, next by agent: Check the ref, or carry on without silta
  human_only  exit 3, next by human: Stop and ask the human in chat; rerun with `--approved "<their words>"` after they say yes
  read_only_promoted  exit 3, next by agent: Leave it to its tracker and pick other work
  ambiguous_location  exit 4, next by agent: Retry with `--app <slug>` from the candidates
  busy  exit 5, next by agent: Retry once after a few seconds
  conflict  exit 6, next by agent: Re-read, then decide; don't steal, and don't unblock while blockers are open
  claimed  exit 6, next by agent: Re-read, then decide; don't steal, and don't unblock while blockers are open
  stale_rev  exit 6, next by agent: Re-read, then decide; don't steal, and don't unblock while blockers are open
  lease_taken  exit 6, next by agent: Re-read, then decide; don't steal, and don't unblock while blockers are open
  blocked  exit 6, next by agent: Re-read, then decide; don't steal, and don't unblock while blockers are open
  gate  exit 7, next by agent: Request a review or ask the human
  rate_limited  exit 8, next by agent: Wait for `retry_after_s`, or summarise
  env  exit 9, next by human: Report the printed fix to the human
An error's own next_by can override its code's default.
