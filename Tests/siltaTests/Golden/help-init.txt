### silta init

OVERVIEW: Initialize or scan repos; select with ws use; ws edit is human-only.

`init --scan` scans roots and two child levels without fetching.
A new workspace derives its slug and task prefix from the first directory.
Values keep case, use letters, digits, _ or -, and start/end alphanumeric.
A --ws scan refreshes that workspace, matching slug without regard to case.
It takes no slug or prefix; a none-named clone is refused with its path.
Example: silta init --scan ~/acme/api ~/acme/web --slug acme --prefix AC

USAGE: silta init [--ws <ws>] [--approved <approved>] [--json] [--quiet] [--verbose] [--scan <scan> ...] [--slug <slug>] [--prefix <prefix>]

GLOBAL OPTIONS:
  --ws <ws>               Use this workspace; default is inferred or saved.
  --approved <approved>   The human's words approving this command in chat;
                          default is none.
  --json                  Print the JSON envelope on stdout; default is text.
  --quiet                 Hide success text; warnings and errors still show.
  --verbose               Mirror command diagnostics to stderr.

OPTIONS:
  --scan <scan>           Scan directories to two child levels; default is
                          none. An existing workspace only refreshes registered
                          repo paths.
  --slug <slug>           Slug for a new workspace; defaults to the first
                          directory's lowercased name.
  --prefix <prefix>       Task prefix; task refs read <prefix>-<n>, e.g. AC-1;
                          defaults to the slug's first two letters, uppercased.
  --version               Show the version.
  -h, --help              Show help information.
